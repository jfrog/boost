❯エージェントで使い始める

Boost が残すもの

Boost はシグナルを保持します：失敗、サマリー、カウント、次の手がかり。繰り返しのストリームはコンテキストを消費する前に圧縮されます。

最も効く場面

エージェントが実行する最もノイズの多いコマンド（テスト、ビルド、ログ）が最も縮みます。

boost — noisy commands
# noisy test runs
pytest -q
go test ./...
npm test

# build & lint logs
npm run build
npx tsc --noEmit
ruff check .

# diffs, logs & debug output
git diff
docker logs app
kubectl logs deploy/api

節約量を測る

Boost は生サイズとフィルタ後のサイズを追跡し、コマンドごとの節約トークンを推定します。合計は boost report、カスタムツールには TOML フィルター を追加します。

# サステナビリティ

排出削減

節約したトークンは燃やさなかったエネルギーです。Boost はトークン節約を推定排出影響に変換し、エージェントがスキップした作業をチームと共有できる数値にします。

boost — emissions
$ boost report

● ターミナルノイズ 170万トークン を節約。

● 359 g CO2e を回避。≈ 100万節約トークンあたり 0.21 kg CO2e。

ノイズ削減 → 計算削減 → 大気中の AI 排出削減。

排出 推定 CO2e 回避量

推定は、100万節約トークンあたりの kg-CO2e の設定可能なヒューリスティックを使用します。監査済みのカーボン会計ではなく方向性のあるサステナビリティ指標ですが、節約したコンテキストが大気への AI 排出削減につながることを具体的に示します。
